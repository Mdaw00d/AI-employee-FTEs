# Odoo Integration Guide

## Overview

This guide explains how to integrate Odoo 19 with the AI Agent system via the MCP (Model Context Protocol) server.

## Architecture

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   Orchestrator  │────▶│  odoo_mcp.py    │────▶│   Odoo 19       │
│   (AI Agent)    │     │  (MCP Server)   │     │   (Localhost)   │
└─────────────────┘     └─────────────────┘     └─────────────────┘
        │                       │                       │
        ▼                       ▼                       ▼
  Needs_Action/           JSON-RPC API           PostgreSQL
  Pending_Approval/       localhost:8070         localhost:5432
```

## Quick Start

### 1. Install Odoo

```bash
# Run the setup script
python odoo_setup.py

# Follow prompts to:
# - Install PostgreSQL (if not installed)
# - Create database
# - Download Odoo Community 19
# - Install Python dependencies
```

### 2. Start Odoo

```bash
# In a terminal (keep running)
cd C:\Odoo19
start_odoo.bat

# Odoo runs at: http://localhost:8069
```

### 3. Start MCP Server

```bash
# In another terminal (keep running)
python odoo_mcp.py

# MCP server runs at: http://localhost:8070
```

### 4. Test Connection

```bash
curl -X POST http://localhost:8070/rpc ^
  -H "Content-Type: application/json" ^
  -d "{\"jsonrpc\":\"2.0\",\"method\":\"health_check\",\"id\":1}"
```

## Integration with Orchestrator

### Trigger Flow

```
1. User/Email creates file in Needs_Action/
   └─> accounting_invoice_001.md

2. Orchestrator detects accounting_* file

3. Orchestrator prompts Qwen Agent:
   "Accounting request detected. Use odoo_accounting skill via MCP."

4. Qwen Agent calls MCP:
   POST http://localhost:8070/rpc
   {
     "jsonrpc": "2.0",
     "method": "create_invoice",
     "params": {
       "partner_id": 123,
       "amount": 5000.00,
       "description": "Consulting Services"
     },
     "id": 1
   }

5. MCP returns result:
   {
     "jsonrpc": "2.0",
     "result": {
       "invoice_id": 456,
       "name": "INV/2026/00001",
       "amount_total": 5000.00
     },
     "id": 1
   }

6. Orchestrator writes result to:
   Done/accounting_invoice_001.md
```

### Orchestrator Code Example

```python
# orchestrator.py - Add this function

import requests
import json
from pathlib import Path

MCP_ENDPOINT = "http://localhost:8070/rpc"

def call_odoo_mcp(method: str, params: dict) -> dict:
    """Call Odoo MCP server."""
    try:
        response = requests.post(
            MCP_ENDPOINT,
            json={
                "jsonrpc": "2.0",
                "method": method,
                "params": params,
                "id": 1
            },
            timeout=30
        )
        return response.json()
    except Exception as e:
        return {"error": str(e)}

def process_accounting_request(file_path: Path):
    """Process accounting request from Needs_Action/."""
    
    # Read request file
    content = file_path.read_text()
    
    # Parse request (simplified - use proper parsing in production)
    # Expected format:
    # Action: create_invoice
    # Partner: Acme Corp
    # Amount: 5000.00
    # Description: Consulting Services
    
    request_data = parse_accounting_request(content)
    
    # Call MCP based on action
    if request_data['action'] == 'create_invoice':
        result = call_odoo_mcp('create_invoice', {
            'partner_id': request_data['partner_id'],
            'amount': request_data['amount'],
            'description': request_data['description']
        })
        
        # Write result
        if 'result' in result:
            output = f"""# Accounting Complete

**Action**: Create Invoice
**Invoice ID**: {result['result']['invoice_id']}
**Invoice Number**: {result['result']['name']}
**Amount**: ${result['result']['amount_total']}
**Status**: Draft

---
Generated by Odoo MCP Server
"""
            (Path("Done") / file_path.name).write_text(output)
        else:
            (Path("Needs_Action") / f"error_{file_path.name}").write_text(
                f"Error: {result.get('error', {}).get('message', 'Unknown error')}"
            )
```

## MCP API Reference

### Accounting Methods

#### create_invoice

Create a customer invoice.

```json
{
  "jsonrpc": "2.0",
  "method": "create_invoice",
  "params": {
    "partner_id": 123,
    "amount": 5000.00,
    "invoice_date": "2026-03-04",
    "description": "Consulting Services - March",
    "reference": "PO-2026-001"
  },
  "id": 1
}
```

Response:
```json
{
  "jsonrpc": "2.0",
  "result": {
    "invoice_id": 456,
    "name": "INV/2026/00001",
    "amount_total": 5000.00,
    "state": "draft"
  },
  "id": 1
}
```

#### get_transactions

Get accounting transactions.

```json
{
  "jsonrpc": "2.0",
  "method": "get_transactions",
  "params": {
    "date_from": "2026-03-01",
    "date_to": "2026-03-31",
    "move_type": "out_invoice",
    "limit": 50
  },
  "id": 1
}
```

#### register_payment

Register payment for an invoice.

```json
{
  "jsonrpc": "2.0",
  "method": "register_payment",
  "params": {
    "invoice_id": 456,
    "amount": 5000.00,
    "payment_date": "2026-03-15",
    "reference": "Wire Transfer #12345"
  },
  "id": 1
}
```

### Partner Methods

#### search_partner

Search for customers/partners.

```json
{
  "jsonrpc": "2.0",
  "method": "search_partner",
  "params": {
    "name": "Acme",
    "limit": 10
  },
  "id": 1
}
```

#### create_partner

Create a new partner.

```json
{
  "jsonrpc": "2.0",
  "method": "create_partner",
  "params": {
    "name": "Acme Corporation",
    "email": "contact@acme.com",
    "phone": "+1-555-1234",
    "street": "123 Business Ave",
    "city": "New York"
  },
  "id": 1
}
```

### System Methods

#### health_check

Check server health.

```json
{
  "jsonrpc": "2.0",
  "method": "health_check",
  "id": 1
}
```

## Error Handling

### Common Errors

| Error | Cause | Solution |
|-------|-------|----------|
| `Not authenticated` | Odoo not running | Start Odoo: `start_odoo.bat` |
| `Partner not found` | Invalid partner_id | Use `search_partner` first |
| `Database connection failed` | PostgreSQL down | `net start postgresql-x64-16` |
| `Timeout` | Odoo busy | Increase timeout, check Odoo logs |

### Error Response Format

```json
{
  "jsonrpc": "2.0",
  "error": {
    "code": -32000,
    "message": "Partner not found: 999"
  },
  "id": 1
}
```

## Platinum Tier: Production Deployment

### HTTPS Configuration

1. Enable in `odoo_setup.py`:
```python
ENABLE_HTTPS = True
```

2. Run setup again to generate certificates

3. Update MCP to use HTTPS:
```python
ODOO_PORT = 443  # or your HTTPS port
```

### Backup Configuration

Automated backups are configured in `odoo_setup.py`:

```python
BACKUP_ENABLED = True
BACKUP_DIR = INSTALL_DIR / "backups"
BACKUP_SCHEDULE = "0 2 * * *"  # Daily at 2 AM
```

Schedule via Task Scheduler:
```cmd
schtasks /Create /TN "Odoo Backup" /TR "C:\Odoo19\odoo_data\scripts\backup.bat" /SC DAILY /ST 02:00
```

### Security Recommendations

1. **Change default passwords** immediately after setup
2. **Enable HTTPS** for any network exposure
3. **Restrict database access** in production:
```ini
# odoo.conf
list_db = False
```
4. **Use environment variables** for credentials:
```python
ODOO_PASSWORD = os.environ.get("ODOO_PASSWORD")
```
5. **Enable firewall** rules for ports 8069, 8070

## Troubleshooting

### Odoo Won't Start

```bash
# Check PostgreSQL
pg_config --version

# Check if port is in use
netstat -ano | findstr :8069

# Check Odoo logs
type C:\Odoo19\odoo_data\logs\odoo.log
```

### MCP Connection Failed

```bash
# Test Odoo directly
curl http://localhost:8069

# Test MCP endpoint
curl http://localhost:8070/rpc -d '{"jsonrpc":"2.0","method":"health_check","id":1}'

# Check MCP logs
type Logs\odoo_mcp.log
```

```bash
\c odoo_db
\dt
```
